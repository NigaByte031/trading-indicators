# Documentation

Background material that is not tied to one language port:

- Explanations of the maths behind the indicators.
- Screenshots and charts (`docs/images/`).
- Usage notes, comparisons and references.
- [Release notes](releases/) — one file per tag, published as the GitHub release
  body when the tag is pushed.

The authoritative behaviour of each indicator lives in [`../specs/`](../specs/);
this folder is for the surrounding prose.
